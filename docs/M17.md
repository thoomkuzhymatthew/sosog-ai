# M17 — Synthetic Prediction Engine v0

Status: Retail baseline implemented; cross-vertical evaluation pending M13–M16.

M17 v0 is a deterministic, zero-inference-cost router. It extracts trace-level
stability and divergence features, produces the six route decisions defined by
the milestone plan, freezes deterministic 70/30 task-ID splits, and reports
cost-weighted held-out regret plus unsafe promotions.

The checked-in Retail regression contains 74 tasks and has zero regressions
against the frozen M3 route labels. On the 21-task Retail held-out split, route
accuracy is 95.238%. The single route miss is task 112; held-out regret is
$0.1536051. The trace categorizer is intentionally reported separately because
its audited accuracy is currently 50% on 20 Retail tasks and therefore bounds
the credibility of automatically generated oracle labels.

The AWS investigation flow does not retune v0 while measurements are running.
Each vertical writes immutable traces to S3 and searchable rows to the
`sosog_research` PostgreSQL schema. Once every track is complete or formally
dropped, the audited corpora are loaded under one snapshot ID. The snapshot
runner refuses to evaluate if any oracle label is missing, writes every v0
prediction back to `sosog_research.router_predictions`, and emits the aggregate
regret artifact. Rule revisions or a learned/hybrid v1 are decided only after
that frozen cross-vertical result exists.

Reproduce the current Retail baseline:

```bash
python scripts/run_m17_predictor.py --check
pytest -q predictor/tests
```

Cross-vertical snapshot flow after audit:

```bash
python scripts/load_m17_snapshot.py --snapshot-id m17-<timestamp> <corpus...>
python scripts/run_m17_research_snapshot.py m17-<timestamp> \
  --output metrics/m17_router_regret_cross_vertical.json
```
