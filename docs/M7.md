## 3. Normalizer Rule

M6 rejected any parse with both `return_item_names` and `keep_item_names` populated. M7 keeps all other M6 checks, but routes this one shape through a stricter deterministic equivalence normalizer.

For a both-list parse, the normalizer:

- Resolves the customer and delivered orders with read-only Retail tools before any write.
- Rejects overlapping return/keep product names.
- Requires every explicit return product to resolve in one delivered candidate order.
- Requires keep products present in that candidate order to resolve unambiguously.
- Requires returned items plus present kept items to account for the whole candidate order; unaccounted products cause deferral.
- Allows an extra keep product outside the candidate order only if it resolves exactly once in another delivered order for the same customer. This is what lets `13_b` pass without allowing an unaccounted item in the returned order.
- Requires exactly one candidate order. Zero or multiple candidates defer.
- Normalizes only proven-equivalent parses to a canonical return-only intent, then calls the unchanged M5 `run_self_resolved(...)` executor.

That last point matters: the normalizer does not write. It either produces a safe canonical intent or returns `DEFER`. Deferred cases never call `return_delivered_order_items(...)`.

## 9. What Broke Or Surprised Me

The normalizer can recover the two known harmless over-defers without reopening either known wrong-write hole. That is the strong M7 result.

The nuance is that safe equivalence is not just "both lists are populated." It needs order-aware proof. `48_b` looks superficially similar to `13_b` and `73_b`, but the order evidence is different: duplicate `Vacuum Cleaner` items and an unaccounted `Dumbbell Set` make the partition unsafe.

The `73_b` recovery also shows why the gate needs a partition view rather than a naive "one product name = one item" rule. A returned product name can legitimately map to multiple item IDs when the full order partition proves that all matching items are in the return set.
