# M0 - On-Demand Bedrock Prerequisites

Date: 2026-08-17

## 1. What Was Built

M0 was redefined and completed using on-demand Bedrock inference instead of Bedrock batch inference. Batch was tested with both `global.anthropic.claude-sonnet-4-6` and `us.anthropic.claude-sonnet-4-6`; both failed before returning a `jobArn` with the same Bedrock account-level `ValidationException`, so batch is treated as an AWS entitlement issue and abandoned for this POC. I then ran a single on-demand `InvokeModel` call in `us-east-1` against `us.anthropic.claude-sonnet-4-6`; it returned text successfully.

The fixed batch resources remain harmless and reusable:

```text
S3 bucket: sosog-bedrock-batch-769377363988
Execution role: arn:aws:iam::769377363988:role/AmazonBedrockExecutionRoleForSosogBatch
```

Local config update: `.env` now sets `BEDROCK_SONNET_MODEL_ID=us.anthropic.claude-sonnet-4-6` so future SOSOG trace generation uses the regional in-region profile.

## 7. Reproduce From Scratch

All commands were run from:

```text
/Users/joshuajooste/Documents/matthew/StartupSpotter
```

Confirm `.env` is ignored:

```bash
rg -n '^\.env$|^\.env\*' .gitignore
```

Load credentials and confirm caller:

```bash
set -a; source .env; set +a
aws sts get-caller-identity --query '{Account:Account,Arn:Arn}' --output json
```

Confirm the fixed S3 bucket:

```bash
set -a; source .env; set +a
aws s3api head-bucket \
  --bucket sosog-bedrock-batch-769377363988 \
  --region us-east-1 \
  --output json
```

Run the on-demand M0 acceptance call:

```bash
set -a; source .env; set +a
REQ=$(mktemp)
OUT=$(mktemp)
jq -n '{
  anthropic_version: "bedrock-2023-05-31",
  max_tokens: 16,
  messages: [
    {
      role: "user",
      content: [
        {
          type: "text",
          text: "Reply with exactly: SOSOG M0 OK"
        }
      ]
    }
  ]
}' > "$REQ"
aws bedrock-runtime invoke-model \
  --region us-east-1 \
  --model-id us.anthropic.claude-sonnet-4-6 \
  --body "fileb://$REQ" \
  --content-type application/json \
  --accept application/json \
  --cli-binary-format raw-in-base64-out \
  "$OUT"
jq '{
  id: .id,
  type: .type,
  role: .role,
  stop_reason: .stop_reason,
  usage: .usage,
  text: ([.content[]? | select(.type == "text") | .text] | join(""))
}' "$OUT"
```
